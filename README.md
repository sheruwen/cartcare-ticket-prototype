# CartCare 客服工單系統 Prototype

CartCare 客服工單系統是一個客服團隊內部使用的前端 mock prototype，用來展示客服案件管理、CartPoints 點數交易排查、客服案件與技術工單協作，以及客服主管營運監控流程。

這版 prototype 聚焦於展示「客服案件管理」、「CartPoints 交易排查」、「客服案件與技術工單關聯」、「客服主管工作看板」四個核心能力，不處理真實登入、權限、API 串接與資料庫。

## 使用者角色

- 一線客服：查看案件、篩選案件、更新狀態、回覆顧客、使用 CartPoints 排查工具。
- 二線客服：處理複雜案件、升級案件、建立或關聯技術工單。
- 技術支援人員：接收技術工單並回報處理進度。
- 客服主管：透過工作看板掌握案件量、超時案件、CartPoints 案件與服務品質。

## 功能範圍

- 案件列表與多條件篩選。
- 案件詳情三欄式工作區。
- 案件狀態更新、指派負責人、內部備註、顧客回覆、升級二線、建立技術工單、關聯既有技術工單與結案。
- CartPoints 排查工具，支援用 User ID 或 Email 查詢 mock 交易。
- 交易列表與交易詳情檢視。
- 一鍵將 CartPoints 查詢摘要附加至案件歷程。
- 技術工單建立 modal 與技術工單卡片展示。
- 案件歷程時間軸，操作後會新增事件。
- 客服主管工作看板與指標案件清單。
- 技術工單、知識庫、設定導覽入口。

## 主要頁面

- 案件列表：客服查看所有案件，並依狀態、類型、優先級、負責人、CartPoints 案件與超時案件篩選。
- 案件詳情：左側為案件基本資訊，中間為操作、對話與歷程，右側為顧客資訊、CartPoints 排查工具與技術工單資訊。
- 工作看板：主管查看待處理、超時、CartPoints、待技術支援等指標，並可點擊指標顯示對應案件清單。
- 技術工單：展示技術工單狀態與多案件關聯情境。
- 知識庫與設定：目前為 placeholder，保留後續擴充。

## Mock Data 說明

Mock data 位於 `src/mockData.ts`。

- 客服案件 8 筆：包含一般訂單問題 2 筆、退款問題 1 筆、CartPoints 點數問題 4 筆、系統問題 1 筆。
- CartPoints 交易資料 5 筆：包含正常完成轉入、處理中轉讓、逾時轉讓、失敗交易、疑似未授權轉出。
- 技術工單 3 筆：其中 `ENG-1188` 關聯 3 個客服案件，用來展示多案件關聯同一張技術工單。
- 客服人員 5 位：一線客服 3 位、二線客服 1 位、技術支援人員 1 位。

所有顧客姓名、Email 與 User ID 都是假資料，不使用真實顧客個資。

## 如何啟動專案

```bash
npm install
npm run dev
```

啟動後開啟終端機顯示的本機網址，通常是：

```bash
http://127.0.0.1:5173
```

## Prototype 的設計取捨

- 使用 React state 模擬資料更新，不串接真實 API。
- 操作結果以畫面狀態與 toast 呈現，不進行資料持久化。
- 圖表以統計卡片與簡單條狀列表呈現，避免引入額外圖表套件。
- 樣式使用一般 CSS，維持乾淨 SaaS 後台風格並降低環境依賴。
- 側重客服處理流程與資訊架構，不實作真實登入、角色權限、資料庫、通知推播或後端排程。
